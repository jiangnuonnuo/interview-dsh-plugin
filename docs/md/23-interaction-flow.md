# 交互图

一场面试分成开场、作答、结束。每一行内部从左到右。作答这一行会重复，直到候选人点结束。

[打开可缩放交互图](23-interaction-flow.html)

## 开场

候选人点输入栏「面试」，在面板里选定主题和难度。Client 建立考场会话。Host 把人设写进系统提示。Agent 在宿主气泡里问出第一题，面板同时给出这一题的开卷要点。

说话发生在 DSH 原来的对话里。考场是项目分组下新开的会话，不是候选人正在写代码的那条对话。

## 作答

候选人仍用宿主输入框回答。面试官按已挂上的人设追问，插件不再往考场里塞一句导演词。

Host 读会话日志，确认这是考生的新答案、并且面试官已经说完，再让 `llm` 生成对照和五维。结果写回右侧卡片。一点没答上时留在原卡；意图达到或换了知识点，才开下一题。知识链替换必须等考场 Agent 空闲。

教练文字不进入气泡，也不作为下一次 `prompt` 发回面试官。

## 结束

面板「结束本场」先停掉看守。Host 摘掉知识链，挂上收尾系统段。这段只给模型看。Client 随后发出可见短句「结束面试」。面试官的收尾出现在考场气泡里。`qa.md` 与 `summary.md` 在同一次结束里写入工作区。

结束后面板回到入口，不切换宿主当前会话，也不删除这场考场对话。
