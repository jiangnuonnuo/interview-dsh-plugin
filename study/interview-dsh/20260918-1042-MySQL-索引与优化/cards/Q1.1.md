# Q1.1

## 题干
针对联合索引 `idx_abc(a, b, c)`，请判断以下查询是否能利用该索引实现覆盖（Extra 中出现 `Using index`），并结合最左前缀匹配说明原因：**

1. `SELECT a, b FROM t WHERE a = 1 AND b = 2`
2. `SELECT a, c FROM t WHERE a = 1`
3. `SELECT b, c FROM t WHERE b = 1 AND a = 2`

## 开卷
针对联合索引idx_abc(a,b,c)，判断三个指定查询是否能利用其实现覆盖索引（Extra出现Using index），并结合最左前缀匹配说明原因
- 覆盖索引核心判定标准：查询所需的所有字段（SELECT列表、WHERE条件查询字段）均包含在所用索引中，无需回表查询聚簇索引，此时Extra会显示Using index
- 联合索引idx_abc(a,b,c)的最左前缀匹配规则：WHERE条件查询列需从索引最左列a开始，按顺序连续匹配，禁止跳过中间列直接使用右侧列，未作为查询条件的中间列不影响覆盖索引判定
- 查询1（SELECT a,b FROM t WHERE a=1 AND b=2）：WHERE条件按序匹配最左前缀的a、b两列，满足最左前缀规则，查询所需的a、b字段均在索引中，可触发Using index
- 查询2（SELECT a,c FROM t WHERE a=1）：WHERE条件匹配最左前缀首列a，满足最左前缀规则，虽未使用中间列b，但查询所需的a、c字段均在索引中，可触发Using index
- 查询3（SELECT b,c FROM t WHERE b=1 AND a=2）：MySQL优化器会自动重排WHERE条件为a=2 AND b=1，匹配最左前缀的a、b两列，满足最左前缀规则，查询所需的b、c字段均在索引中，可触发Using index
