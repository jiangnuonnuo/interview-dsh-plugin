## 0. 本刀完成门槛（先读）

本 change 没有「只写代码就算完」。**实现者必须在正在使用的 DSH Desktop 窗口里看完考场对话**：初级至少一轮追问、高级至少一轮追问，气泡里只有候选人发言和面试官口语，没有知识链、三档菜单、JSON、「请按人设」。否则整份 tasks 视为未完成，8.1 不得勾选，不得归档。

下列不得代替 8.1：`npm test`、`npm run build`、只核对 section 字符串、代码审查、Vite、浏览器打开面板、`doc/entry-panel-mock.html`。

禁止划进本刀：外部决策模型、另配 Key、第二个会说话的 Agent、面板展示三档约束、提示/跳过按钮、为纠正跑题再 `session.prompt`。
