## Why

八股追问现在只靠开场人设里的梯度口号，面试官边听答案边发明下一问；难度只是一句形容词。要点和 `Q1.1` / `Q2` 又是事后凭题干猜的，和这一问要考的不是同一件事。知识链要在候选人作答前写好，并由代码按难度裁剪，同时保证考场气泡仍然只是候选人与面试官的正常对话。

## What Changes

- 新题干落地后，与开卷要点同一次补全产出知识链：知识点、考察层（定义 / 原理 / 场景 / 边界）、考察意图、三档下一问约束（答到了 / 有缺口 / 没答上）。代码按难度裁剪层和同一知识点的题数上限，再把裁剪结果挂到考场 `systemPrompt.section`。追问阶段不得为此 `session.prompt`。
- 难度不再只是入口标签。初级：起手定义，只允许定义与场景，同一知识点最多 2 问。中级：起手原理或场景，允许定义 / 原理 / 场景，最多 3 问。高级：起手取舍或边界，四层都允许，最多 4 问，且「答到了」必须换前提或换规模，边界层同一知识点最多 1 问。问满后 section 里只剩「换知识点」。
- 第一问仍由模型按主题动态生成，不起死题库。只有第一问的起手层写在开场人设里。第一问落地之后，每一问遵守当时挂上的知识链 section，人设里不再用梯度口号充当追问策略。
- 开卷要点从考察意图拆出。评分输入改为考察意图 + 所在层 + 作答。卡片详情增加考察层与考察意图。新题对上三档则为追问编号 `Qn.m`，对上「换知识点」则为下一个 `Qn`。对不上仍建卡，沿用现有编号回退。
- 考场可见消息只保留候选人发言与面试官的自然语言问答。知识链、三档约束、考察意图、评分提示、JSON、`【动作】` 一类导演标记不得进入任何消息气泡。section 文本不得被 `prompt` 或 append 成用户或助手可见内容。插件写入的可见用户句只剩两处：开场「开始本场八股专项模拟面试。」，以及结束时的「结束面试」。现在开场和新一轮开口里的「请按人设…」导演句从气泡中去掉，改留在人设 section。新一轮可见开口仍说明上一轮已结束，并带上新主题与难度。结束本轮时先摘掉知识链 section，再挂收尾段。
- 挂 section 失败或知识链无法解析时，面板可见错误，面试官退回当前人设，卡片仍按今天的要点与评分写。不静默，不丢已有卡。
- 不上外部决策模型，不新增会说话的 Agent，不另配 Key。仍用宿主当前默认模型：开口是考场 Agent，知识链与要点是同一次补全，评分另一次补全。

## Capabilities

### New Capabilities

- `interview-knowledge-chain`：作答前的知识链、难度裁剪、section 挂载、失败回退，以及考场气泡不得出现提示词或链上约束。

### Modified Capabilities

- `interview-session`：第一问按难度规定起手层；开场人设不再用梯度口号驱动后续追问；系统段不得进入消息。
- `interview-follow-up`：下一问遵守已挂上的知识链；追问 / 换知识点按链判定；不得为追问再 `prompt`。
- `interview-cards`：要点来自考察意图；详情展示考察层与考察意图；评分对照该意图与所在层。
- `interview-entry`：难度仍是初级 / 中级 / 高级且不切换死题库，但所选难度会进入知识链裁剪，不再只是保存下来的标签。
- `interview-round-close`：新一轮可见开口不再夹带「请按人设」；结束本轮时摘掉知识链 section。收尾可见短句仍为「结束面试」。

## Impact

- `shared/`：知识链字段、考察层、难度配额、卡片上的考察层与考察意图。Typert 同步。
- `backend/src/services/`：难度裁剪、知识链并入教练 brief、评分输入改为意图与层、人设去掉梯度口号并写上起手层。
- `backend/src/infra/dsh/`：挂载 / 替换 `interview:chain` section。领域层不 import Host SDK。不得把 section 正文写入会话消息。
- `frontend/`：卡片详情展示考察层与考察意图。不新增按钮，不展示三档约束，不出现聊天表面。
- `docs/architecture/ARCHITECTURE.md`：追问约束走 section；难度裁剪在领域层；气泡隔离保持。
- `docs/product/REQUIREMENTS.md`：方向已写入知识链、难度裁剪，以及对话只保留自然语言问答。验收条款仍以本 change 的 spec 为准。
- 验收：仓库单测锁住「约束不进消息」；本机 DSH Desktop 实机核对对话气泡。`npm test` 不能单独过关。
