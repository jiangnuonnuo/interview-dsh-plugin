## 3. 开卡与引导

- [x] 3.1 `miss` 或 `wide_gap` 且 `guideCount` 小于 2：原卡追加一轮作答，`guideCount` 加一，按全文重算对照，不调用追加新卡。单测：两次补充后卡片数量不变，作答有两轮，对照是后一次的结果
- [x] 3.2 `guideCount` 已为 2 且结果仍是 `miss` 或 `wide_gap`：这张卡定稿，不继续加引导次数。此后的新正式问才建卡。单测锁住「第三轮引导不再发生」
- [x] 3.3 `deepen` 与 `reask` 新建 `Qn.m`，`next` 新建下一个 `Qn`。编号不再读取 brief 的 `matchedMove`。原卡题干、要点、作答与分数不被覆盖。单测覆盖这三档
- [x] 3.4 去掉同一知识点 2/3/4 问强制换题。系统段改为写明五种结果该说成引导、子问还是换题，并写入初级、中级、高级的引导尺度；高级的下一正式问要求换前提或换规模。层越界仍裁到该难度允许的最高层。单测：初级段含步骤可点到最后一问，且不再因为题数写「必须换知识点」
- [x] 3.5 知识链字段不合法时用同一道题重试一次。仍不合法则用题干摘要、首条要点和该难度起手层补合法链并挂上系统段，不摘段、不退回人设。系统段接口失败仍是可见的挂载错误。单测覆盖重试命中合法链，以及两次都不合法时补链挂上
